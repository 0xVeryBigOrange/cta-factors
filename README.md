# CTA 多因子看板

加密货币和美股的多因子、多周期多空看板。每个因子在每个周期上给出多头、空头或中性，以及 [-1, 1] 的强度；同一因子可以在 5 分钟上偏多、在 1 小时上偏空。页面是简体中文。

在线地址：[https://0xverybigorange.github.io/cta-factors/](https://0xverybigorange.github.io/cta-factors/)

本站内容只供信息展示和学习，不构成投资建议或交易依据。

## 功能

- 自选列表保存在浏览器 `localStorage`。可以搜索、添加、删除，并按全部 / 加密 / 美股筛选。
- 默认加密：BTC、ETH、SOL、BNB、XRP、DOGE、ADA、AVAX、LINK、DOT。也可以输入其他 USDT 现货代码。
- 默认美股：AAPL、NVDA、TSLA、MSFT、AMZN、META、GOOGL、SPY、QQQ。内置列表里还有一批大盘股和 ETF，任意美股代码也可以添加。
- 周期：5 分、15 分、30 分、1 小时、4 小时、日线、周线。数据源不支持或 K 线不够时，格子显示为不可用，而不是编造信号。
- 因子矩阵：行是分组后的因子，列是周期。绿色为多，红色为空，灰色为中性，颜色深浅表示强度。
- 综合概率：每个周期把全部因子合成一个多头概率。
- 自选总览：全部代码 × 全部周期，可按强多（≥65%）、强空（≤35%）、中性筛选，并可排序。
- 加密在 Binance 公共 WebSocket 可用时实时推送 K 线，否则轮询。页面显示最近刷新时间和最新 K 线时间。

## 数据源与局限

### 加密货币

K 线按下面的顺序尝试，谁先返回足够长度且间隔正确的数据就用谁：

1. **Binance 公共行情** `https://data-api.binance.vision`（现货 K 线，响应带 `Access-Control-Allow-Origin: *`，浏览器可直接访问）。实时推送使用 `wss://data-stream.binance.vision`。
2. OKX 现货 K 线（会按请求来源回显 CORS）。
3. Gate.io 现货。
4. Bitget 现货。
5. Kraken。
6. Coinbase（没有 30 分、4 小时、周线；历史也更短）。
7. CoinGecko OHLC（没有成交量，粒度粗，只适合作为日线 / 4 小时级别的最后兜底）。

`api.binance.com` 和 `fapi.binance.com` 在部分网络会返回 451，因此没有把它们当作主源。Bybit 在部分地区也会被拦住，所以没有放进回退链。

衍生品只对加密显示，来自 **Gate.io** 的公开合约统计、资金费率历史和标记价 / 指数价。Gate 失败时改用 **Bitget** 的资金费率和账户多空比；Bitget 这条路径没有持仓量历史，持仓量因子会空着。小币如果没有 USDT 永续，整组衍生品为空。

这些读数不是每个周期都有原生 K 线：

- 资金费率大约 8 小时一条。短周期至少看最近 8 小时，长周期看更长的平均。
- 持仓量和多空比用 5 分、1 小时、日线历史拼在一起，再按当前周期的回看窗口取变化。窗口盖不住就留空。
- 基差是实时快照，七个周期是同一个数。

### 美股

Yahoo Finance 图表接口 `query1.finance.yahoo.com/v8/finance/chart` **没有浏览器 CORS**，页面不能直接请求。本仓库用两种互补方式：

1. **GitHub Actions 预取（主路径）**。`Deploy GitHub Pages` 在推送到 `main`、手动触发，以及每 2 小时的定时任务里，用 Yahoo 拉 `src/data/universe.json` 里的美股，写成 `public/data/equities/<SYMBOL>.json`，再和静态站一起发布。4 小时没有原生周期，由 1 小时 K 线按 UTC 时间桶聚合。价格是图表接口的前复权（拆分已调整）OHLC，没有再做股息调整。
2. **腾讯行情（浏览器补齐）**。`web.ifzq.gtimg.cn` 和 `qt.gtimg.cn` 允许跨域。已缓存的代码用它刷新报价；还没被 Actions 收录的代码，用它提供日线和周线。腾讯这条线目前拿不到可用的美股分钟 K，所以自定义代码的 5 分到 4 小时会标成不可用。行情可能延迟，休市时显示最近收盘。

定时任务由 GitHub 调度，实际运行时间可能晚于 cron。两次发布之间，因子用的是上一次缓存，报价可以比 K 线更新。

本地开发时，如果还没有 JSON 缓存，Vite 会把 `/yahoo` 代理到 Yahoo，这样任意代码也能算出全部周期。`npm run fetch-equities` 可以预先生成缓存。只拉一部分代码：`ONLY=AAPL,SPY npm run fetch-equities`。

### 频率限制

每个数据源有自己的请求间隔。K 线按周期缓存（5 分约 20 秒，日线约 5 分钟），自选里当前代码优先加载，其余代码先加载日线和 1 小时。请求失败或 429 会退避，短时间不再打已经不可用的源。

## 综合概率

1. 因子输出强度 s ∈ [-1, 1]。正为多，负为空，接近 0 为中性（强度记 0）。
2. 在每个类别内部对强度做简单平均。
3. 六个类别再等权平均，得到总分 S。因子多的类别不会压过因子少的类别。
4. 没有数据的因子不参与。某一类完全没有数据时，这一类被拿掉，其余类别重新平均。
5. 多头概率 = 1 / (1 + e^(−3S))。S = 0 时为 50%，S = 1 时约 95%，S = −1 时约 5%。

这是因子投票的映射，不是未来涨跌的胜率。

## 本地开发

```bash
npm ci
npm test
npm run fetch-equities
npm run dev
```

开发服务器是 `http://localhost:5173/`。`npm run build && npm run preview` 用和 GitHub Pages 相同的相对路径检查构建结果。

## 部署

`.github/workflows/pages.yml` 在推送到 `main` 时测试、抓取美股缓存、构建，并用 `actions/configure-pages`、`actions/upload-pages-artifact`、`actions/deploy-pages` 发布。工作流会尝试把 Pages 的构建方式设为 GitHub Actions（需要仓库令牌具备管理权限；若仓库策略不允许，需要在仓库 Settings → Pages 里把 Source 选成 GitHub Actions）。

页面地址：`https://0xverybigorange.github.io/cta-factors/`。

`.github/workflows/ci.yml` 在 pull request 上运行测试和构建，不访问外网。
